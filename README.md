# Gästbok

Det här är ett konsolprogram i C# som fungerar som en gästbok.
Man kan lägga till inlägg, ta bort inlägg och visa alla inlägg.
Alla inlägg sparas i en fil så att de finns kvar nästa gång man startar programmet.

## Funktioner

- Lägga till ett inlägg genom att skriva namn och text
- Ta bort ett inlägg genom att ange index
- Visa alla inlägg
- Spara inläggen i en fil som heter guestbook.json
- Läsa in inläggen från filen när programmet startar

## Instruktioner

1. Öppna en terminal i projektmappen
2. Skriv: dotnet run
4. Följ menyn som visas i konsolen
